# Voting Veranda

## Voting Veranda is an online voting system that can be used for a variety of purposes, such as tracking the number of voters as well as presenting information in a straightforward and comprehensible way. This application allows voters to perform their civic duties from the comfort of their home, candidates to easily keep track of their performance, and administrators to find any discrepancies and declare the victor.

## Functional Requirements
- Provide a list of options the user can vote for.
- Retain the information of all votes made.
- Display the standings of each category in a stacked bar chart as well as the total votes.
- *Voter*: vote for chosen candidate, view voter information, and candidate campaigns.
- *Candidate*: view current standings, campaigns, and candidate information.
- *Admin*: track the number of voters, view the results of the election, and see the information of all users.

## Non-functional Requirements
- **Security**: Users should be able to log in the system and have their information kept secure; unauthorized users should not be able to log in to vote, candidate or administrator pages.
- **Accuracy**: The system should calculate vote counts and should not display inaccurate results.
- **Usability**: The system should be usable and understandable to voters, candidates, and administrators.
- **Reliability**: The system should not crash while in use during the voting process and should be able to allow voters to cast a vote.
- **Performance**: The system should load pages and process votes without too many delays.
- **Maintainability**: The system should be designed to be easily modified, debugged, and enhanced in the future by members of the team.
